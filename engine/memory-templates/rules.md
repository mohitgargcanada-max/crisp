# Memory Rules

## Save Automatically When Safe

- Repo paths.
- Stable user preferences.
- Durable project decisions.
- Commands that worked.
- Tool install state.
- Repeated gotchas.

## Ask Before Saving

- Personal information.
- Sensitive/private context.
- Financial, health, client, or legal details.
- Anything ambiguous.

## Never Save

- Secrets.
- API keys.
- Passwords.
- OAuth tokens.
- Recovery phrases.
- Raw private documents.
